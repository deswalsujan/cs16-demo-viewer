## What the game does, read before building

- ReGameDLL `client.cpp` (`Host_Say`, `SendSayMessage`): a chat line is SayText with the sender's entity index, a format (`#Cstrike_Chat_CT`, `_T`, `_CT_Dead`, `_T_Dead`, `_Spec`, `_All`, `_AllDead`, `_AllSpec`), an empty name (the client fills it in from its player list) and the text with a line end. A living receiver gets no dead sender's line and a dead one no living sender's, unless the sender is the HLTV; team chat goes to the sender's team only. So an HLTV demo has only dead players' all-chat.
- ReGameDLL `player.cpp` (`CBasePlayer::Radio`): with each radio sound (SendAudio) to the sender's team and anyone watching one of them, a TextMsg to `HUD_PRINTRADIO` (5): the sender's entity index as text, `#Game_radio`, his name, the phrase (`#Fire_in_the_hole`); `#Game_radio_location` with a place on servers with `location_area_info`.
- cs16-client `saytext.cpp`: `MAX_LINES` 5; `hud_saytext_time` 5: once the top line is up 5 s it scrolls off, the next 5 s later; a line when 5 are up pushes the top one out; a line wider than the screen less 40 wraps at its last space, the rest a line starting with a space that scrolls off with it; `Y_START` set when a line comes in (`ScreenHeight - 60` playing, `ScreenHeight * 4 / 5` spectating, less 6 line heights); colour bytes `\x01` yellow, `\x03` the sender's team colour, `\x04` green. `text_message.cpp`: the radio line's phrase localised, the name not. `util.cpp`: yellow 255 179 0, red 255 64 64, blue 153 204 255, grey 204, green 0 255 0; a sender with no team grey.
- The player's `cstrike_english.txt` (Mac copy, 25th Anniversary build): `Game_radio` `\x02%s1 (RADIO): %s2`; `Cstrike_Chat_CT` `\x01(Counter-Terrorist) \x03%s1\x01 :  %s2`, and the same for the others; `Cstrike_Chat_All` `\x02%s1 :  %s2`. Every radio phrase the POV demos send is there as `Cstrike_TitlesTXT_<name>`. No `Game_radio_location`.
- `\x02`: cs16-client draws it as nothing; Valve's HLSDK `saytext.cpp` draws a line starting with it in the sender's team colour up to the end of his name. Sujan's YouTube POV has the radio lines yellow throughout. Sujan's answer (28 Nov 2026): a living player's all-chat name in the team colour, so the HLSDK rule for chat, the radio yellow.
