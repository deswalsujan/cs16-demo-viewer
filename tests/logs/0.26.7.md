## The change

- `src/ui/folder.js` finds `sound/materials.txt` in the picked folder (cstrike's, else valve's, as the game's file system does) and reads it in Chrome's remembered folder too (`HL_WANT`). `loadMaterials` (`src/ui/wallbangs.js`) reads it as the game's `TEXTURETYPE_Init` does: Sujan's file has 701 lines and 689 names (12 names twice; one, `generic015v`, as grate first and metal later, and the first line wins in the game and here). `loadMap` waits for it before the finder runs.
- `hitTextures` (`src/bsp.js`) finds the texture where a line enters each surface `solidAlong` found on it. `wallKeeps` takes the killer's crosshair line at the shot (the line the finder already uses), and of its surfaces the best material's share: metal 0.2, grate 0.4, vent and computer 0.45, tile 0.3, wood 0.6, the rest 0.5; 0.6 when the folder has no materials list or a surface's face isn't found. `tooMuchDamage` uses it in place of 0.6. The hit rule in `computeHits` is unchanged.
